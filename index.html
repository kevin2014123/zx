灵界系统接入

内置“灵界 OS”轻量级浏览器操作系统引导页。一键下载、自动拉起安装器，无缝体验包含 17 个内置应用的独立系统。

⏱️

极简时间工具

精准设备时间实时同步，支持正计时与倒计时。Tabs 极简切换，丝滑且直观。

🔐

安全密码生成器

基于底层 SecureRandom 强随机数，自定义数字、字母与特殊符号，生成无懈可击的终极密码。

🐍

独立 Python 引擎

内置纯正官方运行库，纯手工 JNI 桥接，无需任何第三方软件即可在手机上极速运行 Python 脚本(不需要连接网络）。

🔏

APK 本地签名

调用官方 apksig 引擎，零网络依赖本地执行。完美防同名覆盖拦截，拒绝原包被毁。

📦

ZIP 智能解压

支持 AES 加密压缩与解密解压，自带同名目录覆盖提示保护，精准守护你的数据安全。

📱

应用列表探秘

突破系统限制，一键罗列所有已安装应用。支持查看图标、包名、快捷复制与拉起系统卸载。

📊

底层系统探针

极客专属，一键读取设备真实底层参数。精准硬核检测 Bootloader 上锁状态与 Root 权限。

🎇

全屏弹幕跑马灯

输入任意文字，选择炫彩颜色。瞬间点亮全屏横屏无限滚动，聚会整活必备神器。

🤖

AI 双棋对战

纯手工极小化极大算法，内置五子棋与井字棋，三种地狱级难度挑战你的智商。

🔤

简繁转换器

基于 Android 底层 ICU 库，极速且原汁原味地实现简体中文与繁体中文的双向互转。

📷

二维码生成器

纯本地渲染，无任何网络请求。支持生成纯文本或网页跳转二维码，支持超清保存。

🎂

年龄精准计算

输入出生年份与当前年份，瞬间计算出你的精确年龄与存活天数，记录时间的流逝。

💌 开发者的话

大家好，我是 ZX 工具箱的开发者。这不是一个用现代框架随便套壳的软件，它是我用纯手工命令行，从底层一行行敲出来的作品。
