全能工具箱

VERSION 1.0
🐍 独立 Python 引擎

内置完整原生动态库，无需配置环境，即点即跑代码，支持彩色 ANSI 输出。

📦 ZIP 智能压缩/解压

支持 AES 加密压缩与密码解压，自带同名文件安全覆盖提示。

📊 底层系统探针

读取真实设备参数，硬核检测 Bootloader 锁与 Root 越权状态。

🤖 AI 五子棋

内置极小化极大算法的 AI 对手，支持三种难度挑战。

🎮 AI 井字棋

永远不会放水的 AI，挑战你能否在最高难度下取得平局。

🔤 简繁转换

基于底层 ICU 库，极速、精准地进行简体与繁体中文互转。

📱 应用列表探秘

一键罗列系统所有应用，查看图标、包名，支持快捷复制与卸载。

🔏 APK 本地签名

纯内存调用官方 apksig 引擎，无需外部命令，一键签名你的安装包。

📷 二维码生成器

支持生成纯文本或网页跳转二维码，无第三方依赖，极速渲染。

🎇 全屏弹幕跑马灯

输入文字，选择颜色，瞬间点亮全屏，支持横屏无限滚动播放。

🎂 年龄精确计算

输入出生年份与当前年份，快速计算年龄及存活天数。

⚙️ 硬件深度控制

支持手电筒快捷开关、音量精准调节、屏幕亮度强制改写。
